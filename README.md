# 🏠 EstateAI - AI House Price Prediction System

<p align="center">

An end-to-end Machine Learning web application that predicts house prices using advanced regression techniques and a FastAPI-powered interface.

</p>


## 🚀 Project Overview

EstateAI is an AI-powered real estate price prediction system that uses Machine Learning to estimate property prices based on important housing features.

The project combines:

- Machine Learning model development
- Data preprocessing
- Feature engineering
- Model deployment
- FastAPI backend
- Interactive web interface

Users can enter property details such as quality, living area, year built, bedrooms, garage capacity, and neighborhood to receive an estimated house price instantly.
